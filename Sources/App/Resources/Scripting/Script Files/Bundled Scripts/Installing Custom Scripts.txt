
Custom scripts can be installed in the folder:

"~/Library/Application Scripts/com.vakesz.glasstual/"

This folder might not exist. If it does not, create it. Glasstual does
not have write permission to this location so it cannot create it on
its own. Scripts installed within this folder benefit from the ability
to be ran outside of the macOS sandbox giving them unrestricted access
to the system as a whole.

Scripts are only read from this folder, never from inside the
application bundle. This is an unfortunate design flaw of the macOS
sandbox that Glasstual cannot circumvent.
