Keyboard shortcuts in Glasstual

These shortcuts work in the main window. Menus show the shortcut beside each command.

Conversations

Command-Shift-OChannel Search
Command-Option-FFilter Sidebar
Option-TabGo to the previously selected conversation
Command-Shift-+Add Channel
Command-TModify Topic
Command-Option-,Channel Properties
Command-Shift-,Server Properties
Command-Shift-LView Logs
Command-Shift-BList of Bans
Command-Shift-EList of Ban Exceptions
Command-Shift-IList of Invite Exceptions

Transcript

Command-FFind in the conversation
Command-G / Command-Shift-GFind Next / Find Previous
Command-Shift-FFind in All Conversations
Command-LMark Scrollback
Command-Control-LGo to the scrollback marker
Command-Shift-UMark All as Read
Command-KClear Scrollback
Command-= / Command-- / Command-0Increase, decrease or reset the font size
Command-Control-TMove the keyboard focus to the transcript
Command-PPrint

Message field

ReturnSend
Command-ReturnSend as an action
TabComplete a nickname, channel or command
Up Arrow / Down ArrowPrevious or next sent message
Control-P / Control-NPrevious or next sent message
EscapeCancel a reply or close suggestions
Command-B / Command-I / Command-UBold, italic, underline
Control-Shift-C / Control-Shift-HText color / background color

Windows

Command-1Main Window
Command-2People
Command-3Show Logs in Finder
Command-4Highlight List
Command-5Transcript Logs
Command-Option-LFile Transfers
Command-Control-SHide or show the sidebar
Command-Option-IHide or show the member list
Command-Control-FEnter or exit full screen
Command-Shift-MMute Notification Sounds
Command-,Settings
Command-?Glasstual Help

To choose what the Tab key and Command-W do, open Glasstual > Settings, then click Controls.
