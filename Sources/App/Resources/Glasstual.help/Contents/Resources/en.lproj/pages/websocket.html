Connect to a WebSocket server

Some networks accept IRC connections over WebSocket, for example when only web ports are open.

Use a WebSocket endpoint

  1. Select the server, then choose Server > Server Properties.
  2. In the General pane, choose WebSocket as the connection type.
  3. Enter the server address, the port, and the path the gateway listens on, such as /irc or /webirc/websocket/. The path starts with a slash.
  4. Select Connect securely to use wss://, WebSocket over TLS. Without it, the connection uses unencrypted ws://.
  5. Click Save, then reconnect.

Alternate servers can mix IRC and WebSocket endpoints; the list shows each one’s type and path.

You can also switch the selected server with /transport websocket /path or back with /transport irc.
