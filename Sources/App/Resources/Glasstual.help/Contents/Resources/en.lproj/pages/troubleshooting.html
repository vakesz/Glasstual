If Glasstual doesn’t work as expected

You can’t connect

  • Check the server address and port in Server Properties > General, and that Connect securely matches the port, often 6697 for TLS and 6667 without it.
  • If Glasstual reports an untrusted certificate, see Connect securely.
  • If you use Tor, open Tor Browser first. If you use another proxy, check its address in the Proxy Server pane, or hold down Option and choose Server > Connect Without Proxy.
  • If the network uses a WebSocket gateway, check the connection type and path; see Connect to a WebSocket server.

Your nickname is taken

Add alternative nicknames in Server Properties > Identity, or type /nick newname. If the nickname is registered to you, sign in to your account.

Sign-in fails

  • Check the SASL mechanism and the account name in Server Properties > Identity. The pane names any missing password, certificate, key or token.
  • If Use Only This Mechanism is selected, Glasstual doesn’t try another one.
  • If your password wasn’t sent, the server’s certificate wasn’t checked or the connection wasn’t encrypted; see Connect securely.
  • After fixing the problem, choose Server > Sign In Again.

Channels don’t join

  • Some channels need you to be signed in. In Server Properties > Identity, select “Wait for identification before joining channels.”
  • Joining many channels at once can look like an attack to some networks. Open Glasstual > Settings, click Connection, then increase the delay under Flood Control.

File transfers fail

Transfers need a direct connection between computers. Check the IP address detection and port range in File Transfers settings, or ask the other person to send the file while you use passive requests. See Send and receive files.

Images don’t appear

  • Check “Show inline images” in Style settings and “Show inline media” in Channel Properties.
  • On a server with an HTTP or SOCKS proxy, click the image placeholder to load it.
  • Glasstual loads only HTTP and HTTPS images.

Messages are missing after you reconnect

If a banner says some messages weren’t loaded, click Load Missing Messages. The server must keep history; see Catch up on history and search it.

Notifications don’t appear

Check that notifications are allowed for Glasstual in System Settings > Notifications, and that Glasstual isn’t muted in its View menu or by a Focus.

Get more help

Choose Help > Connect to Help Channel to ask other Glasstual users.
