Use a bouncer

A bouncer stays connected for you and replays what you missed. Add it like any server, using the address, port, username and password the bouncer gives you.

ZNC

In Server Properties, click ZNC Bouncer to choose whether Glasstual skips joining channels on connect, skips notifications for the playback buffer, and plays back only the messages you missed. These options need ZNC 1.2 or later.

Use /detach to stop following a channel while the bouncer stays in it, and /attach to follow it again. /znccert shows the certificate the bouncer reports.

soju networks

A soju account can hold several networks. Glasstual shows each one as its own server under the account in the sidebar.

  1. Select the bouncer’s server, then choose Server > Server Properties.
  2. Click Bouncer Networks. Select “Show the bouncer’s networks as servers” and, if you like, “Hide this connection when it has networks.”
  3. While connected, click Add Network, or select a network and click Edit Network or Delete Network.

Each network connects on its own and signs in with the bouncer account. Its server, identity and security settings come from the bouncer connection. When a network is deleted, its conversations stay in Glasstual, read-only.
