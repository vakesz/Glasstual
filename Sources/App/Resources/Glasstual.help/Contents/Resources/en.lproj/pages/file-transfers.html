Send and receive files

Files and direct chats go straight between your Mac and the other person’s computer, not through the IRC server. The other person learns your IP address.

Send a file

  • Control-click a member, then choose Send File or Send File Securely.
  • Or drag files onto a private conversation or onto a member. Glasstual asks before sending.
  • Or type /dcc send nickname followed by the file’s path.

Receive a file

When someone offers you a file, Glasstual does what you chose in Glasstual > Settings > File Transfers: open a dialog, download automatically or ignore the offer. Files are saved to your Downloads folder unless you choose another one.

Choose Window > File Transfers to see every transfer. From there you can accept an offer, cancel a transfer, try again to resume one, show a file in the Finder, preview it with Quick Look or open it. Received files are marked as downloaded from the internet, so macOS checks them when you open them.

If transfers can’t connect

In File Transfers settings:

  • Choose how Glasstual finds your Mac’s IP address, or enter it yourself.
  • Set the range of ports to use, and allow them through your router.
  • Select “Send passive file transfer requests” so the other side connects to you only when it can.

Start a direct chat

Type /dcc chat nickname. When someone asks to chat with you, Glasstual shows their address and asks whether to accept.

Request packs from XDCC bots

  • Control-click a bot’s pack announcement, then choose Request Pack, or choose Get Pack Info.
  • Or type /xdcc get bot #pack. /xdcc list bot asks for the bot’s list; /xdcc requests shows your pending requests.

Pending requests appear under Waiting for Bots in the File Transfers window, with your place in the bot’s queue. To let a requested pack download on its own, select “Treat packs I request from XDCC bots as coming from people I know” in File Transfers settings; the pack must still fit the other conditions shown there.
