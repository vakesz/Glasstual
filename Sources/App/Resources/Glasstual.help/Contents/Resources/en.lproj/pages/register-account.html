Register an account

On networks that support it, you can create an account without leaving Glasstual.

Register

  1. Select the server, then choose Server > Register Account. If you aren’t connected, Glasstual connects to register.
  2. Enter the account name. Some servers name the account after your nickname; to pick another, choose Server > Change Nickname first.
  3. Enter your email address if the server asks for one, then enter and verify a password.
  4. Click Register.
  5. If the server sends a verification code, enter it from your email, then click Verify.

When registration succeeds, Glasstual saves the password in your keychain and signs in with SASL from then on.

If the server’s certificate wasn’t checked, Glasstual asks before it sends the password. If the connection should be encrypted but isn’t, Glasstual doesn’t send it.

You can also use /register and /verify.
