Reply to, react to and delete messages

Replies, reactions and deleting messages need a server that supports them. On other servers, the commands aren’t available.

Reply to a message

  1. Control-click the message, then choose Reply. A banner above the message field shows who you’re replying to.
  2. Type your reply, then press Return. To cancel, click Cancel Reply.

In a channel, choose Reply Privately to answer only the sender. Your private reply stays linked to the channel.

React to a message

Control-click the message, then choose a reaction. Choose Custom Reaction or More Emoji for others. Reactions appear below the message; click one to add the same reaction.

Delete a message

  1. Control-click a message you sent, then choose Delete Message.
  2. Enter a reason if you want, then click Delete.

The server removes the message for everyone in the conversation, and this can’t be undone. When someone deletes a message, Glasstual shows “Message deleted”; choose Show Original Message to see what it said, if it’s still stored.

Send several lines

When you paste text with several lines, Glasstual can send it as one multiline message if the server supports it, or line by line. Before sending a large message, it asks first.

Delivery

When the server confirms messages, a message you send shows as pending until it arrives. If it fails, click Retry.
