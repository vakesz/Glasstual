Reply to, react to and delete messages

Replies, reactions and deleting messages need a server that supports them. On other servers, the commands aren’t available.

Reply to a message

  1. Control-click the message, then choose Reply. A banner above the message field shows who you’re replying to.
  2. Type your reply, then press Return. To cancel, click Cancel Reply.

In a channel, choose Reply Privately to answer only the sender. Your private reply stays linked to the channel.

To see the message a reply answers, Control-click the reply, then choose Show Original Message.

React to a message

Control-click the message, choose React, then choose an emoji. Choose Other to type a custom reaction or pick from more emoji. Reactions appear below the message; click one to add the same reaction.

Delete a message

  1. Control-click a message you sent, or any message in a channel where you’re an operator, then choose Delete Message.
  2. Enter a reason if you want, then click Delete.

The server removes the message for everyone in the conversation, and this can’t be undone. When someone deletes a message, Glasstual shows “Message deleted” in its place.

Send several lines

When you send text with several lines and the server supports multiline messages, Glasstual asks whether to send it as one message or line by line. If the text is longer than the server accepts, you can send the first part as one message instead.

Delivery

When the server confirms messages, a message you send shows as pending until it arrives. If it fails, a warning symbol and the reason appear beside it.
