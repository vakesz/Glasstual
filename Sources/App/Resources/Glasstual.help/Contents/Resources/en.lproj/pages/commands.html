Slash commands in Glasstual

Type a command in the message field, starting with a slash. As you type, Glasstual suggests matching commands with their syntax. Words in angle brackets are required; words in square brackets are optional.

To send a line that starts with a slash as an ordinary message, start it with two slashes.

Conversations

Join, leave and move between channels and private conversations.

/join [channel[,channel]] [key[,key]]Also: /jJoin one or more channelsSeparate channels and their keys with commas. With no channel, rejoins the selected channel.
/leave [channel] [reason]Also: /partLeave a channel or close a private conversationOmit the channel to use the selected channel.
/cycleAlso: /hop, /rejoinLeave and rejoin the selected channel
/query <nickname> [message]Open a private conversationEnter a nickname and optionally a first message.
/close [target]Also: /removeClose a conversationOmit the target to close the selected conversation.
/goto <name fragment>Switch to a matching conversationType part of a channel or conversation name. Searches across all networks.
/listBrowse the network’s channels
/names <channel> [more channels]Request channel member namesSeparate multiple channel names with spaces.
/invite <nickname> [more nicknames] [channel]Invite people to a channelSeparate nicknames with spaces. The optional channel comes last.
/topic [channel] [topic]Also: /tRead or change the channel topicOmit the channel to use the selected channel. Omit the topic to read it.
/autojoinJoin the configured automatic channels
/setqueryname <nickname>Retitle the selected private conversationEnter the user’s nickname on this network.

Messages

Send messages, actions and notices.

/msg <target[,target]> <message>Also: /umsgSend a message to a person or channelUse a nickname or channel as the target. Separate multiple targets with commas.
/me <message>Also: /umeSend an action in the selected conversationType the message after the command. Spaces are part of the message.
/notice <target[,target]> <message>Also: /unoticeSend an IRC noticeUse a nickname or channel as the target. Separate multiple targets with commas.
/whisper <nickname> <message>Whisper privately to a member from this channelUse in a channel. The message is private and marked as belonging to the channel.
/smsg <target[,target]> <message>Send a message without echoing it locallyUse a nickname or channel as the target. Separate multiple targets with commas.
/sme <target[,target]> <message>Send an action without echoing it locallyUse a nickname or channel as the target. Separate multiple targets with commas.
/omsg [channel] <message>Send a message to channel operatorsOmit the channel to use the selected channel.
/onotice [channel] <message>Send a notice to channel operatorsOmit the channel to use the selected channel.
/amsg <message>Send a message to all joined channelsSends to every joined channel. Settings determine whether other connections are included.
/ame <message>Send an action to all joined channelsSends to every joined channel. Settings determine whether other connections are included.
/redact [message id [reason]]Delete a message in the selected conversationThe message id is the message's msgid tag. Without a message id, your most recent message in the conversation is deleted. Requires server support for message redaction.
/ctcp <nickname> <command> [arguments]Send a CTCP requestEnter a nickname and a CTCP command such as VERSION or PING.
/ctcpreply <nickname> <command> [arguments]Send a CTCP replyEnter a nickname and a CTCP command such as VERSION or PING.

People

Find out about people and control what you see from them.

/whois [nickname]Look up a user’s informationOmit the nickname in a private conversation to look up that person.
/whowas <nickname>Look up a previously used nicknameEnter the user’s nickname on this network.
/who <channel|mask> [flags]Request information about matching usersReplace <placeholders> with values. Items in [brackets] are optional.
/ison <nickname> [more nicknames]Check which nicknames are onlineSeparate multiple nicknames with spaces.
/monitor L | S | CAlso: /watchInspect the server’s online-status listL lists entries, S requests status, C clears the list. Add or remove people in the People window.
/silence [<+|-><mask|nickname>]Manage the server-side silence listUse + to add a mask or - to remove one. With no arguments, requests the list. Requires server support.
/ignore [nickname]Add an ignore rule for a userEnter a nickname. If no matching user is available, the People window opens for editing.
/unignore [nickname]Remove an ignore rule for a userEnter a nickname. If no matching user is available, the People window opens for editing.
/muteMute notification sounds
/unmuteRestore notification sounds
/setcolor <nickname>Choose a nickname’s display colorEnter the user’s nickname on this network.

Connection and account

Connect, change your nickname and status, and sign in.

/server <address> [[+]port] [password]Connect to another IRC serverPrefix the port with + to use TLS, for example +6697.
/conn [server]Connect or reconnect to this networkOmit the server to reconnect to the current endpoint.
/quit [reason]Disconnect from this networkThe reason is optional and can contain spaces.
/nick <nickname>Change your nicknameEnter the user’s nickname on this network.
/away [reason]Mark yourself as awayThe reason is optional and can contain spaces.
/backClear your away status
/setname <real name>Change your real nameThe real name may contain spaces. Requires server support for SETNAME.
/umode [flags] [arguments]View or change your user modesReplace <placeholders> with values. Items in [brackets] are optional.
/pass <password>Send a server connection passwordReplace <placeholders> with values. Items in [brackets] are optional.
/sasl [status | auth [mechanism] | mechanism <name | automatic> [only] | token <token | clear>]Show or change how SASL signs instatus lists the account and each mechanism. auth signs in again now. mechanism sets which one signs in first; only stops fallback. token stores an OAuth token in the keychain.
/register [<account|*> <email|*> <password> | cancel]Register an account on the server* names the account after your nickname or leaves out the email. Without arguments, shows what the server accepts. The command is never kept in input history.
/verify [account|*] <code>Verify a newly registered account with its codeWithout an account, the code completes the registration in progress. The command is never kept in input history.
/metadata [target] <get|list|set|clear|sub|unsub|subs|sync> [arguments]Show or change the profile data people and channels set on the serverWithout a target the command is about you. set <key> <value> stores a value, set <key> "" an empty one, and set <key> alone removes it.
/transport [irc | websocket [path]]Show or change how the first server is reachedWithout arguments, shows the current transport. Changes apply on the next connect.
/sslcontextInspect this connection’s TLS certificate

History and display

Load history and manage the transcript.

/chathistory <latest | before | after | around | between | targets | fill> [target] [arguments]Request history from the serverServer support is required. latest, before, after, around and between fetch messages; targets finds conversations you missed; fill loads missing messages.
/clearClear the selected transcript
/clearallClear transcripts on configured connections
/notifybubble [channel] <message>Show a local notificationAn optional channel links the notification to that conversation.
/notifysound <sound name>Play a notification soundEnter the name of a system notification sound, such as Glass.

Files and direct chats

Send files, start direct chats and request packs.

/dcc chat|schat [nickname] | send|ssend <nickname> <path> | accept|decline <id> | trust <id> <answer> | fingerprint | certificates [nickname] | forget <nickname>Start a direct chat or send a fileUse chat for a direct conversation or send with a file path for a file transfer.
/xdcc send|get <bot> <#pack> | batch <bot> <packs> | list <bot> | info <bot> <#pack> | cancel [bot] | remove <bot> [#pack] | requestsRequest packs from XDCC bots and manage the requestsPacks are numbers such as #5; batch takes a list such as 1-5,7, at most 20 packs.
