Add a server in Glasstual

Each server in the sidebar is one connection to an IRC network. You can add as many as you like.

Add a server

  1. Choose File > Add Server, or click the Add Server button in the toolbar.
  2. Choose a network to fill in its address, port and encryption, or choose Custom Server to enter your own. A network may suggest channels; they’re added to the server’s channel list, where you can remove any of them.
  3. Check the settings in the General pane:
    • Server Address and Port: Where to connect. You can also type a network name, such as Libera.Chat, to fill in its details.
    • Connect securely: Encrypts the connection with TLS. See Connect securely.
    • Server Password: Sent with the PASS command when connecting. Most networks don’t use one; it isn’t your account password.
    • Connect when Glasstual opens and Reconnect after disconnect: Keep you connected without doing anything.
  4. Click Identity to set your nickname for this server and, if you have an account, how to sign in. See Sign in to your account.
  5. Click Save.

You can also add a server by typing /server followed by its address, for example /server irc.example.org +6697. A plus sign before the port connects securely.

Connect and disconnect

Select the server in the sidebar, then choose Server > Connect or Server > Disconnect. While Glasstual waits to reconnect, choose Server > Cancel Reconnect to stop it.

If the server uses a proxy, hold down the Option key and choose Server > Connect Without Proxy to connect once without it.

Use alternate servers

In the General pane, click Modify Alternate Servers to list other addresses for the same network. Glasstual tries them from top to bottom; the first is the primary server.

Change a server’s settings

Select the server, then choose Server > Server Properties. The panes cover your identity and profile, the channel list, highlights, commands sent on connect, quit messages, text encoding, bouncers, the client certificate, the network socket, the proxy and flood control.

Each server’s properties open in a window of their own, so you can keep them open while you chat. Click Save or press Command-S to apply your changes, or click Revert to go back to the saved settings. If you close a window with unsaved changes, or quit, Glasstual asks whether to save them.

To ignore someone on a server or to be told when they come online, choose Window > People.

To make a copy of a server, choose Server > Duplicate Server. To remove one, choose Server > Delete Server.
