Set your server profile

On servers that support profiles, you can set a display name, a picture and a color that people see beside your nickname in apps that support them.

Change your profile

  1. Connect to the server, select it, then choose Server > Server Properties.
  2. Click Profile, then enter a display name, a picture address (an http or https URL), or choose a profile color.
  3. Click Update Profile.

Changes go to the server right away; they aren’t part of Save. If the server limits how often you can change your profile, Glasstual waits and tells you how long. Click Revert to undo your edits, or Remove Profile from Server to clear it.

See other people’s profiles

Open Glasstual > Settings, click Style, then select “Show names, pictures and colors people set on the server.” Pictures also need inline images, and aren’t loaded on a server that uses an HTTP or SOCKS proxy. The nickname is always shown beside a name, and colors are adjusted so names stay legible.

For more control, use /metadata.
