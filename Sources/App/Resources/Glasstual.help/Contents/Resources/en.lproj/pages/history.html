Catch up on history and search it

Messages from the server

When a server keeps history, Glasstual loads recent messages as you join and fills gaps after you reconnect. If some messages couldn’t be loaded, a banner says so; click Load Missing Messages.

Scroll up to load earlier messages. Click Return to Live to go back to the newest ones.

To turn this off, open Glasstual > Settings, click IRCv3, then deselect “Restore recent messages from the server.” For more control, use /chathistory.

History on your Mac

To keep conversations between sessions, open Glasstual > Settings, click General, then select “Restore scrollback from previous session.”

Search all conversations

  1. Choose Edit > Find > Find in All Conversations.
  2. Type words to find. You can limit the search to this server or this conversation, to one nickname, or to dates.
  3. Select a result to go to the message.

Transcript logs

Glasstual can also write each conversation to text files.

  • To turn logging on, open Glasstual > Settings, click Advanced, select “Save transcripts to disk,” then choose a folder.
  • To read the logs, choose Window > Transcript Logs, or choose Channel > View Logs for the selected channel.
  • To open the folder in the Finder, choose File > Show Logs in Finder.
