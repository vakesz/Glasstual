Connect through a proxy or Tor

Each server can use its own proxy. A proxy hides your address from the IRC network.

Choose a proxy

  1. Select the server, then choose Server > Server Properties.
  2. Click Proxy Server, then choose a type of proxy:
    • None: Connect directly.
    • Automatic: Use the proxy set in System Settings. Click Open System Settings to change it.
    • HTTP Proxy or SOCKS 5 Proxy: Enter the proxy’s address and port, and a username and password if it needs them. The password is stored in your keychain.
    • Tor Anonymity Network: Connect through Tor Browser, which must be running before you connect.
  3. Click Save, then reconnect.

To connect once without the proxy, hold down the Option key and choose Server > Connect Without Proxy.

Images and the proxy

Glasstual never bypasses a server’s proxy to show an image:

  • With Tor, inline images load through Tor.
  • With an HTTP or SOCKS proxy, an image shows as “Load image from” its host. Click it to load the image through the proxy. Network icons aren’t loaded.
  • If the proxy has no address, nothing is loaded.
