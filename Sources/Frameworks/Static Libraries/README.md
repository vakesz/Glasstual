# Former static-library collection

This directory originated as a collection of prebuilt static libraries. No
static library remains: the native transcript removed the final template-engine
consumer in 2026-08. The directory retains the collection's BSD license and
this provenance note.

libgpg-error, libgcrypt and libotr, together with the Encryption Kit framework
that linked them, were removed on 2026-08-22 (LGPL 2.1; see
`../PROVENANCE.md`). Their build scripts went with them.
